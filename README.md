# リミナルスペース写真保管庫

リミナルスペースな写真を保管するリポジトリです。当リポジトリの画像を利用する場合、以下のライセンス及びクレジット表記に関する記載を**必ず**ご確認ください。

## 画像のライセンスについて

当リポジトリの`photos/`以下に配置されている画像ファイルは、全て[CC BY 4.0ライセンス](https://creativecommons.org/licenses/by/4.0/deed.ja)で公開します。

上記ファイルを除く当リポジトリ内の全てのファイルは、無断での複製、改変、公開を禁止します。

### クレジット表記の際の注意点

クレジット表記におけるタイトル及び著作者(及びそのURL)は、以下のように記載してください。

| 要素 | 内容 |
| ---- | ---- |
| タイトル | ファイル名から、拡張子部分を除外したもの。<br> (例：ファイル名が「ABC.jpg」 ならば、「ABC」がタイトルとなる) |
| 著作者 | けろゆー |
| 著作者のURL[^1] | https://www.flickr.com/people/187133233@N06/ |

[^1]:実際のクレジット表記に含めるかどうかは任意でよい。
